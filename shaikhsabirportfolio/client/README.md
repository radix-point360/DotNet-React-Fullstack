# Shaikh Sabir Shaikh Taher - Professional Portfolio

A high-performance, professional React + Tailwind CSS portfolio featuring glassmorphism UI, interactive project category filters, animated metrics, dark/light mode toggle, direct Call & WhatsApp action links, automatic email client launch, clipboard copy feedback, and PDF resume download.

## Deployment on Vercel

1. **Add your PDF Resume:** Place your resume PDF file named `Resume_ShaikhSabir_DotNetFullStack.pdf` inside the `public/` folder.
2. **Local Development:**
   ```bash
   npm install
   npm run dev
   ```
3. **Deploy to Vercel:**
   - Push this repository to GitHub.
   - Import into Vercel. Vercel will automatically detect Vite and configure the build settings (`npm run build` & `dist`).
